# FSWD Lab 8 — VOID IN VACCUM STORE

Full Stack Web Development (FSWD) Lab 8 coursework.

## Project Overview
- **Store Name**: VOID IN VACCUM STORE
- **Frontend**: Responsive storefront in HTML5 and Bootstrap 5 (`Lab8/T6Void_Iz_VaccumStore/T6_Void_iz_VAccum_Store.html`).
- **Backend**: Modular NestJS REST API with Controllers, Modules, and Services (`Lab8/T6Void_Iz_VaccumStore/backend/`).
  - No pipes or guards
  - No database (in-memory services)
  - No authentication

## Running the Backend
```bash
cd Lab8/T6Void_Iz_VaccumStore/backend
npm install
npm run start:dev
```
Server runs on `http://localhost:3000`.

## Testing with Postman
Import `Lab8/T6Void_Iz_VaccumStore/backend/postman_collection.json` into Postman to test all GET and POST requests.
