VOID IZ VACCUM — Bootstrap storefront coursework

Files:
- index.html: responsive static storefront using HTML, Bootstrap 5 CSS, and a small amount of custom CSS for visual styling.

How to run:
1. Extract the ZIP.
2. Open index.html in a browser.
3. Internet access is needed for Bootstrap CSS and the Unsplash product photography.

Important:
- No JavaScript is included.
- Cart, checkout, product buttons, and newsletter signup are visual-only as requested.
- Product imagery is loaded from Unsplash URLs.
