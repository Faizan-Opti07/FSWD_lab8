Abstract—Modern websites must adapt to phones, tablets and desktops. This paper compares four CSS layout techniques: tables, floats, Flexbox and CSS Grid. Each technique was used to build the same web page, and the results were measured for code size, load time and responsiveness. The results show that CSS Grid and Flexbox need less code and give better responsive behavior than older methods.

Keywords—HTML, CSS, Flexbox, Grid, responsive design, web layout

I. Introduction

Web layout has changed a lot in the last twenty years. Early developers used HTML tables to place content, while later developers moved to floats and positioning [1]. Today, Flexbox and CSS Grid are the standard tools for creating flexible layouts [2].

A good layout must work on many screen sizes without extra code. This paper studies how the four main techniques perform on the same design and explains which one is best for student and professional projects.

II. Methodology

A. Test Page

A single page was designed with a header, a navigation bar, a two-column content area and a footer. The page was rebuilt four times, once for each layout technique, using only HTML and CSS.

B. Evaluation Metrics

Three metrics were used: (1) lines of CSS code, (2) page load time in milliseconds, and (3) a responsiveness score out of 100. The score is the average of the layout quality at three screen widths, as shown in (1).

R = (Sm + St + Sd) / 3 (1)

where Sm, St and Sd are the scores for mobile, tablet and desktop screens.

III. Implementation

Tables were used with the table tag, floats with the float property, Flexbox with display: flex, and Grid with display: grid. All pages used the same colors, fonts and content to keep the test fair.

  • Table layout: fixed structure, hard to change.
  • Float layout: needs clearing and extra fixes.
  • Flexbox: best for one-dimensional rows or columns.
  • Grid: best for two-dimensional page layouts.

V. Conclusion

This study compared four CSS layout techniques. Flexbox and Grid produced shorter code, faster pages and better responsive behavior. Developers should use Grid for full page layouts and Flexbox for smaller components. Future work can test more browsers and larger websites.
